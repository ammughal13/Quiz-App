# Quiz App

An interactive quiz application built with HTML, CSS, and JavaScript.

## Live Demo

[Play the Quiz](https://ammughal13.github.io/Quiz-App/)

## Features

- Multiple-choice questions
- Interactive answer selection
- Visual feedback for correct and incorrect answers
- Score tracking
- Final score display
- Restart quiz functionality
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

This project was built to practise JavaScript arrays, objects, functions, DOM manipulation, event handling, conditional logic, and score tracking.
